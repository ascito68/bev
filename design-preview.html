Attuale — problemi
  • • Palette Tailwind di default senza sistema
  • • Tutti i card identici (stesso peso visivo)
  • • Font di sistema, nessun carattere tipografico
  • • Favicon = logo Vite
  • • FAB Material Design generico
A — Instrument Panel
  • • Sfondo quasi-nero, si sente il "tech"
  • • Verde-teal = risparmio, dati come hero
  • • Font Inter, numeri grandi e luminosi
  • • Gerarchia chiara tra sezioni
  • • Richiede più rework, aspetto più netto
B — Italian Racing
  • • Header nero + accento rosso = personalità forte
  • • Typography condensata, lettere maiuscole
  • • PHEV evidenziato su sfondo rosso
  • • Stile editoriale/automotive premium
  • • Polarizzante — o piace molto o poco
C — Evoluzione conservativa
  • • Hero card viola a piena larghezza = gerarchia
  • • Font Inter, border-radius variabile
  • • Stessa struttura attuale, molto migliorata
  • • Rischio minimo, deploy veloce
  • • Non stravolgente ma riconoscibile
